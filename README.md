# LiuqihaoMod

## 关于mod
LiuqihaoMod是一个适用于mc26.1+的neoforge模组，加入了一些奇奇怪怪的东西。
包括byte、short、int、long、float、double、boolean、char、    及其数组版本。
**警告：    为危险品，使用后可能导致服务器崩溃。**

## 模组版本
当前Mod适用于mc26.1,需求的neoforge最低版本为:26.1.2.76.  
此Mod没有前置Mod。

## 测试版
0.0.8.8测试版：
[liuqihao-0.0.8.8test1.zip](https://github.com/user-attachments/files/32655901/liuqihao-0.0.8.8test1.zip)

### 安装
1. 安装NeoForge 26.1.2.76+  
2. 解压zip，将jar放入mods文件夹  
3. 启动游戏
