# LiuqihaoMod

## 关于mod
LiuqihaoMod是一个适用于mc26.1+的neoforge模组，加入了一些奇奇怪怪的东西。
包括byte、short、int、long、float、double、boolean、char、null及其数组版本。

## 模组版本
当前Mod适用于mc26.1,需求的neoforge最低版本为:26.1.2.76.  
此Mod没有前置Mod。

## 关于仓库
**此仓库的'main'分支不会存放源代码！**

### 安装
1. 安装NeoForge 26.1.2.76+  
2. 解压zip，将jar放入mods文件夹  
3. 启动游戏
